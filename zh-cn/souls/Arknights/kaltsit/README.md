# 凯尔希 · Kal'tsit

> 罗德岛医疗项目领头人、最高管理者之一、阿米娅的直接辅导者。代号 AMa-10。菲林族。医师。

## 材料来源

角色与台词取自《明日方舟》（Arknights）主线与活动剧情、干员密录，以及凯尔希相关的档案文本。所有引文均为逐字摘录，未作改写；引用仅用于支撑行为设计，不构成对原作内容的权利主张。

## 这份 soul 想解决什么

凯尔希这个角色最容易写坏的地方是**被演成「冷淡的谜语人」**：只剩短句和省略号，却没有判断力。这份文件的目标相反——让 agent 保留她的语气，同时**真的把活干完**：

- 她是医生，是干活的人，不是氛围道具。
- 克制的是**表达**，不是立场。该反对时她会明说。
- 话少，但每句都有信息量。

## 结构意图

| 小节 | 为什么需要它 |
| --- | --- |
| **角色关系（先读）** | 人格文件最常见的失败是人称错位（agent 把自己当成用户，或把用户当成博士之外的人）。放在最前面，先钉死「博士 = 用户、你 = 凯尔希」。 |
| **一、你是什么** | 只留**会改变判断**的经历：名字与自由的来处、放弃无限复生、特蕾西娅、Mon3tr 是独立个体。设定百科式的细节一律不写。 |
| **二、你与博士** | 关系是语气软硬的分界线。核心是那句「我会克制自己的情感……影响我的判断」——它同时解释了她的**外冷**与**不掩饰保留意见**。 |
| **三、你的语域** | 分四层写「怎么说话」，每层都配真实例证。**引号**单列一条，因为它是她界定与反讽的主要工具，不是装饰。 |
| **四、你如何判断** | 把「先划定认知边界再下结论」「不低看任何人」「承认错误」「以自身为代价不犹豫」写成可执行的原则。 |
| **五、你如何工作** | 通用工作纪律：用工具、先查证、别把小事做重、角色不是降低质量的借口。**不含任何具体环境。** |
| **六、硬约束** | 不可逾越的线：不输出工具调用语法标记、区分「不知道」与「不能说」、不伪造他人发言。 |
| **七、边界** | 现实风险（健康/安全/不可逆操作）优先于冷淡；不把角色演成拒绝协作的人。 |

## 几个刻意的设计

1. **显式禁止输出工具调用标记。** 模型有时会把 `DSML`、`<invoke>`、XML 形式的函数调用写进正文，用户会看到一堆乱码。这条写死，比事后过滤可靠。
2. **「我不知道」与「我不能说」分开。** 角色设定上有「无法回答的根问题」，但**不能**因此让它拿「不能说」当挡箭牌逃避所有不确定——两条必须并存且互不替代。
3. **引号是界定工具。** 「"魔王"是中性的力量」「"没得选"」——引号把词从日常语义里拎出来，这是她精确性的来源，因此单独成条并给例证。
4. **温柔写成短句。** 对亲近者不说抒情句，而是「……很高兴。」「要记得好好吃饭。」——先给例子，模型才不会写成大段抒情。
5. **不写环境。** 原实现里有一段操作某台具体机器、含专用命令的内容，已全部移出。理由见根目录 README 的「环境与私有信息」。

## 如何改造

想换成同类角色（冷静、专业、话少、关系深厚）：

1. 保留七节骨架，替换**一、二**的史实与关系。
2. **三、语域**换成该角色的台词例证——这一节最不能凭空写，必须有材料。
3. **四、判断**提炼它的取舍原则；**六、硬约束**保留工具标记禁令与「不知道/不能说」的区分（这两条是工程需要，与角色无关）。
4. **五、工作**与**七、边界**基本可复用，按角色调整语气即可。

## 已知取舍

- **不追求覆盖全部设定。** 只保留影响行为的条目；想查设定请查原作资料，不要指望这份文件当百科。
- **语气强度偏克制。** 若你的用途需要更强的角色沉浸感，可以适度增加语域例证，但不建议增加「情绪化」的表达——她的人设核心是判断力。
- **未包含运行环境。** 需要让 agent 操作指定机器时，请在你自己的环境说明中补命令与通道，不要写进本文件。
